# ShopSmart

A simple e-commerce app built with React and the DummyJSON API.

## Run it

1. npm install
2. npm run dev
3. Open the link shown in the terminal

## Features

- Product list with pagination
- Debounced search
- Category filter
- Sort by price and rating
- Product details page
- Cart with quantity controls and total

## Folder structure

- src/api.js: all API calls
- src/hooks/useDebounce.js: delays the search
- src/components: small, reusable components
- src/App.jsx: holds the main state
